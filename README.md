# تطبيق «المهام» – طريقة الحصول على ملف APK

1. أنشئ حسابًا مجانيًا في github.com ثم مستودعًا جديدًا (New repository).
2. ارفع كل محتويات هذا المجلد إلى المستودع، ومنها المجلد المخفي `.github`
   (إن لم يظهر عندك: Add file ← Create new file، واكتب المسار `.github/workflows/build.yml` والصق محتوى الملف).
3. افتح تبويب **Actions** ← **Build APK** ← انتظر نحو 5 دقائق حتى يظهر ✔.
4. افتح التشغيلة الناجحة، ونزّل **Almahaam-APK** من قسم Artifacts، وفك الضغط لتحصل على `app-debug.apk`.
5. انقل الملف للهاتف وثبّته (اسمح بالتثبيت من مصدر غير معروف عند الطلب).

إن فشل البناء: انسخ نص الخطأ الأحمر من سجل الخطوة «Build debug APK» وأرسله لي.
